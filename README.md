RAÇÃO 109 is a hands-on software project inspired by operational challenges in pet retail. Its goal is to replace fragmented manual processes with a more organized, mobile-friendly workflow for teams and managers.

**Key modules and capabilities developed and iterated on:**

- **Expiration date management:** register products by barcode (EAN), expiration date, quantity, and store location; search, sort, and filter records.
- **Barcode scanning:** mobile camera scanning and manual EAN entry, including handling codes with leading zeros.
- **Cloud data:** Supabase database and storage integration for shared records and uploaded verification photos.
- **Role-based interfaces:** tailored functionality for team members, management, and sector leaders.
- **Printable labels:** custom layouts for A4 printing, including multi-item label preparation.
- **Expiration monitoring:** track products and deadlines, with workflows for time-sensitive items.
- **Activity verification:** mobile selfie capture as part of an operational evidence workflow.
- **Data quality and recovery:** work on record consolidation, duplicate prevention, quantity consistency, backups, and recovery workflows.
- **Responsive design:** adapted interfaces for desktop and mobile, with deployments using Cloudflare Pages and Netlify.

**Technologies and tools:** `HTML` · `CSS` · `JavaScript` · `Supabase` · `SQL` · `Cloudflare Pages` · `Netlify` · `ZXing`

> **Project status:** Active development and testing. I am continuously improving reliability, synchronization, barcode scanning, and user experience.
>
> **Note:** The project is intended for internal workflows. Code, production data, and organizational information are not publicly shared without authorization.

**What this project has taught me:** translating business requirements into software features, iterative development, debugging real user issues, database integration, permissions, and mobile-first UX.
